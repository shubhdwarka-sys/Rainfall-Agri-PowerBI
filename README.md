# 🌾 Agricultural Productivity Analysis (Power BI)

## 📌 Overview

This project analyzes agricultural data to understand production, area, and productivity across Indian states.

## 🎯 Objective

* Analyze state-wise production
* Study area vs production relationship
* Identify productivity patterns

## 🛠 Tools Used

* Power BI
* Power Query
* DAX

## 📊 Key Insights

* Higher area leads to higher production
* Productivity varies across states
* Efficiency is a key factor

## 📂 Files

* Power BI Dashboard (.pbix)
* Dataset (.csv)
